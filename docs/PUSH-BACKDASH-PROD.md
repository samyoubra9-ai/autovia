# Web Push — Backdash (désactivé)

Les **notifications push navigateur** pour le backdash auto-école sont **désactivées**.

Les moniteurs et gérants utilisent la **cloche in-app** (absences examen, expiration dossier, etc.) — pas de popup système.

Le Web Push reste actif **uniquement pour l’app candidat** (`candidat.autovia.space`).

Voir `docs/PUSH-CANDIDAT-PROD.md` pour la configuration candidat.
