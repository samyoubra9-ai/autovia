# Fin d'obligation

Déposez ici les images des panneaux de **fin d'obligation** (rectangulaires barrés).

Chaque fichier correspond à une entrée dans `content/apprentissage/panneaux.json` → section `obligation` → `fin` :

| Fichier | Id JSON | Panneau de début associé |
|---------|---------|--------------------------|
| `obligeadroite.webp` | C1-fin | C1 — sens obligatoire à droite |
| `pistecycles.svg` | C2-fin | C2 — piste ou bande obligatoire pour cycles |
| `cheminpieton.svg` | C3-fin | C3 — chemin obligatoire pour piétons |

Après ajout de l'image, complétez `name` et `meaning` dans le JSON.
