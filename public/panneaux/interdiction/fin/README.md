# Fin d'interdiction

Déposez ici les images des panneaux de **fin d'interdiction** (rectangulaires barrés).

Chaque fichier correspond à une entrée dans `content/apprentissage/panneaux.json` → section `interdiction` → `fin` :

| Fichier | Id JSON | Panneau de début associé |
|---------|---------|--------------------------|
| `interditagauche.svg` | B0-fin | B0 — interdit de tourner à gauche |
| `interditdestationner.svg` | B1-fin | B1 — stationnement / arrêt interdit |
| `pieton.webp` | B3-fin | B3 — accès interdit au piéton |
| `sensinterdit.webp` | B9a-fin | B9a — sens interdit |
| `limitation.webp` | B31 | B14 — limitation de vitesse |

Après ajout de l'image, complétez `name` et `meaning` dans le JSON.
