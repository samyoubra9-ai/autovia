# Section balisage

Balises, mûrs de guidage et bornes. Images servies sous `/panneaux/balisage/…`.

| Fichier | Id JSON | Description |
|---------|---------|-------------|
| `musoir.webp` | J1 | Mûr de guidage (musoir) |
| `borne.webp` | J2 | Borne kilométrique ou de délimitation |
| `balise.webp` | J3 | Balise de signalisation |

Entrées dans `content/apprentissage/panneaux.json` → `vertical` → `balisage`.
