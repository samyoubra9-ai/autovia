# Images de la landing Autovia

Remplacez les fichiers SVG par vos captures (WebP ou PNG recommandé).

1. Gardez le **même nom de fichier** ou mettez à jour `app/components/landing/landing-data.ts`.
2. Tailles conseillées :
   - `hero-dashboard` : 1280×800
   - `showcase-*` (desktop) : 1200×750
   - `showcase-candidat` : 390×844 (mobile)
